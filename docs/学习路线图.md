# FinRobot 学习路线图

> 从零开始系统学习FinRobot项目，为面试做好充分准备

## 📅 学习计划（建议2-3周）

### 第一周：基础理解（7天）

#### Day 1-2: 项目概览和环境搭建
**时间：** 4-6小时

**学习目标：**
- ✅ 理解项目背景和定位
- ✅ 搭建开发环境
- ✅ 运行第一个示例

**学习任务：**
1. 阅读 `README.md` 了解项目概况
2. 阅读 `docs/FinRobot项目详解-面试准备指南.md` 第1-3章
3. 搭建开发环境：
   ```bash
   # 创建虚拟环境
   conda create --name finrobot python=3.10
   conda activate finrobot
   
   # 克隆项目
   git clone https://github.com/AI4Finance-Foundation/FinRobot.git
   cd FinRobot
   
   # 安装依赖
   pip install -e .
   ```

4. 配置API密钥：
   - 复制 `OAI_CONFIG_LIST_sample` 为 `OAI_CONFIG_LIST`
   - 复制 `config_api_keys_sample` 为 `config_api_keys`
   - 填入你的OpenAI API密钥和Finnhub密钥

5. 运行第一个示例：
   ```bash
   cd tutorials_beginner
   jupyter notebook agent_fingpt_forecaster.ipynb
   ```

**检查点：**
- [ ] 能够成功运行Market Forecaster示例
- [ ] 理解了四层架构的基本概念
- [ ] 了解AI Agent的三要素

#### Day 3-4: 核心概念深入
**时间：** 6-8小时

**学习目标：**
- ✅ 深入理解AI Agent工作原理
- ✅ 掌握Financial CoT概念
- ✅ 理解工具调用机制

**学习任务：**
1. 阅读文档第4章（核心模块详解）
2. 阅读 `docs/架构图解.md` 理解架构设计
3. 深入代码：
   ```python
   # 阅读这些关键文件
   finrobot/agents/workflow.py
   finrobot/agents/agent_library.py
   finrobot/toolkits.py
   ```

4. 动手实践 - 创建自定义Agent：
   ```python
   # 在notebook中实验
   from finrobot.agents.workflow import SingleAssistant
   import autogen
   
   # 配置
   llm_config = {...}
   
   # 创建agent
   agent = SingleAssistant("Market_Analyst", llm_config)
   
   # 尝试不同的查询
   agent.chat("分析AAPL的投资价值")
   ```

5. 画出架构图（手绘或用工具）

**检查点：**
- [ ] 能用自己的话解释Perception-Brain-Action
- [ ] 理解工具是如何注册和调用的
- [ ] 能够画出四层架构图

#### Day 5-6: 数据源和功能模块
**时间：** 6-8小时

**学习目标：**

- ✅ 理解功能模块的实现

**学习任务：**
1. 学习数据源模块：

## 🎯 学习方法建议

### 高效学习技巧

1. **主动学习**
   - ✅ 不要只看代码，要运行和修改
   - ✅ 每学一个概念就尝试实践
   - ✅ 写代码比看代码更重要

2. **记录笔记**
   - ✅ 用自己的话总结核心概念
   - ✅ 画图帮助理解架构
   - ✅ 记录遇到的问题和解决方法

3. **循序渐进**
   - ✅ 从简单到复杂
   - ✅ 先理解再深入
   - ✅ 不要跳步骤

4. **多维度学习**
   - ✅ 看文档
   - ✅ 读代码
   - ✅ 看论文
   - ✅ 实践项目

5. **费曼学习法**
   - ✅ 尝试教别人
   - ✅ 写技术博客
   - ✅ 录制讲解视频

### 常见陷阱和注意事项

#### ❌ 不要做：

1. **浅尝辄止**
   - 只运行tutorial但不理解原理
   - 不深入阅读源代码
   - 不尝试修改和扩展

2. **死记硬背**
   - 背答案而不理解
   - 记API而不懂原理
   - 背架构图而不理解设计理由

3. **过度自信**
   - 认为自己完全理解了
   - 不准备edge case
   - 面试时夸大贡献

4. **忽视基础**
   - 跳过Python基础
   - 不了解LLM原理
   - 缺乏金融知识

#### ✅ 要做：

1. **理解原理**
   - 搞清楚为什么这样设计
   - 理解技术选型的理由
   - 知道优缺点和适用场景

2. **动手实践**
   - 运行所有示例
   - 修改代码观察结果
   - 完成扩展项目

3. **真诚表达**
   - 承认这是学习的项目
   - 强调自己的理解和思考
   - 展现学习能力和热情

4. **持续学习**
   - 关注项目更新
   - 阅读相关论文
   - 参与社区讨论
