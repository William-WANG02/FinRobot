## 3. Financial Chain-of-Thought 流程图

```
财报分析的Financial CoT流程：

Step 1: 数据收集
   │
   ├─→ get_sec_report(ticker, year)
   │      └─→ 获取10-K报告
   │
   └─→ get_company_info(ticker)
          └─→ 获取基本信息
   │
   ▼
Step 2: 利润表分析
   │
   ├─→ get_income_stmt(ticker)
   │      └─→ 获取利润表数据
   │
   ├─→ analyze_income_stmt()
   │      ├─→ 收入分析（YoY/QoQ）
   │      ├─→ 成本结构分析
   │      ├─→ 利润率分析
   │      └─→ EPS分析
   │
   └─→ 生成分析段落 (400-450字)
   │
   ▼
Step 3: 资产负债表分析
   │
   ├─→ get_balance_sheet(ticker)
   │
   ├─→ analyze_balance_sheet()
   │      ├─→ 资产结构
   │      ├─→ 流动性分析
   │      ├─→ 偿债能力
   │      └─→ 股东权益
   │
   └─→ 生成分析段落
   │
   ▼
Step 4: 现金流分析
   │
   ├─→ get_cash_flow(ticker)
   │
   ├─→ analyze_cash_flow()
   │      ├─→ 经营活动现金流
   │      ├─→ 投资活动现金流
   │      └─→ 融资活动现金流
   │
   └─→ 生成分析段落
   │
   ▼
Step 5: 风险评估
   │
   ├─→ 从10-K提取风险因素
   │
   ├─→ LLM分析主要风险
   │      ├─→ 市场风险
   │      ├─→ 运营风险
   │      └─→ 财务风险
   │
   └─→ 生成风险分析段落
   │
   ▼
Step 6: 可视化
   │
   ├─→ plot_pe_ratio(ticker)
   │      └─→ 生成市盈率图表
   │
   └─→ plot_eps(ticker)
          └─→ 生成EPS趋势图
   │
   ▼
Step 7: 生成PDF报告
   │
   ├─→ build_annual_report()
   │      ├─→ 组合所有段落
   │      ├─→ 插入图表
   │      ├─→ 应用专业排版
   │      └─→ 输出PDF文件
   │
   ▼
Step 8: 质量检查
   │
   ├─→ check_text_length()
   │      └─→ 验证字数要求
   │
   ├─→ 如不符合 → 返回Step 2重新生成
   │
   └─→ 确认完成 ✓
```

## 4. 工具注册和调用机制

```
┌────────────────────────────────────────────────────────┐
│              Tool Registration & Calling               │
└────────────────────────────────────────────────────────┘

阶段1: 函数定义
─────────────────────────────────────────────────────
def get_stock_data(
    symbol: Annotated[str, "ticker symbol"],
    start_date: Annotated[str, "start date, YYYY-mm-dd"],
    end_date: Annotated[str, "end date, YYYY-mm-dd"]
) -> DataFrame:
    """Retrieve stock price data for designated ticker symbol"""
    # 实现代码
    return stock_data

                │
                ▼

阶段2: AutoGen处理
─────────────────────────────────────────────────────
register_toolkits([get_stock_data], caller, executor)
                │
                ├─→ 提取函数签名
                ├─→ 解析类型注解
                ├─→ 读取文档字符串
                │
                ▼
生成工具描述 (JSON Schema):
{
  "name": "get_stock_data",
  "description": "Retrieve stock price data...",
  "parameters": {
    "type": "object",
    "properties": {
      "symbol": {
        "type": "string",
        "description": "ticker symbol"
      },
      "start_date": {...},
      "end_date": {...}
    }
  }
}
                │
                ▼

阶段3: 添加到LLM上下文
─────────────────────────────────────────────────────
System Message:
"You are a financial analyst. You have access to tools:
 - get_stock_data: Retrieve stock price data..."

                │
                ▼

阶段4: LLM决策
─────────────────────────────────────────────────────
User: "获取AAPL最近一个月的股价"

LLM分析 → 决定调用工具 → 生成function call:
{
  "name": "get_stock_data",
  "arguments": {
    "symbol": "AAPL",
    "start_date": "2024-10-21",
    "end_date": "2024-11-21"
  }
}
                │
                ▼

阶段5: 执行工具
─────────────────────────────────────────────────────
AutoGen接收function call
      │
      ├─→ 验证参数
      ├─→ 调用Python函数
      └─→ 捕获返回值
                │
                ▼
返回结果给LLM:
"Tool result: [DataFrame with stock data]"

                │
                ▼

阶段6: LLM处理结果
─────────────────────────────────────────────────────
LLM接收数据 → 分析 → 生成回答:

"根据获取的数据，AAPL在过去一个月的价格从$150涨到$180，
涨幅20%，呈现强劲上涨趋势..."
```

## 8. 关键设计模式

### 装饰器模式
```python
@decorate_all_methods(init_ticker)
class YFinanceUtils:
    def get_stock_data(...):
        # 自动获得init_ticker功能
```

### 策略模式
```python
agents = {
    "Market_Analyst": strategy_for_market_analysis,
    "Expert_Investor": strategy_for_report_generation,
    "Trade_Strategist": strategy_for_trading
}
```

### 工厂模式
```python
def create_agent(agent_name, llm_config):
    config = agent_library[agent_name]
    return FinRobot(config, llm_config)
```

### 观察者模式
```python
# AutoGen的消息传递
agent1.send(message, agent2)  # agent2观察agent1的消息
```
